Dual GTM install for www.mastercraftutah.com
============================================

Add dealer-managed Google Tag Manager container GTM-WBRVRFZX alongside the
existing platform container GTM-NP4S3KHX. Both containers must remain active
and load on every page. This is a standard dual-install pattern.


STEP 1 — Paste this inside <head>, as high in the <head> as possible
--------------------------------------------------------------------

<!-- Google Tag Manager — Dealer container -->
<script>(function(w,d,s,l,i){w[l]=w[l]||[];w[l].push({'gtm.start':
new Date().getTime(),event:'gtm.js'});var f=d.getElementsByTagName(s)[0],
j=d.createElement(s),dl=l!='dataLayer'?'&l='+l:'';j.async=true;j.src=
'https://www.googletagmanager.com/gtm.js?id='+i+dl;f.parentNode.insertBefore(j,f);
})(window,document,'script','dataLayer','GTM-WBRVRFZX');</script>
<!-- End Google Tag Manager — Dealer container -->


STEP 2 — Paste this immediately after the opening <body> tag
------------------------------------------------------------

<!-- Google Tag Manager (noscript) — Dealer container -->
<noscript><iframe src="https://www.googletagmanager.com/ns.html?id=GTM-WBRVRFZX"
height="0" width="0" style="display:none;visibility:hidden"></iframe></noscript>
<!-- End Google Tag Manager (noscript) — Dealer container -->


VERIFICATION
------------
Once installed, View Source on https://www.mastercraftutah.com/ should show
BOTH "GTM-NP4S3KHX" (existing) AND "GTM-WBRVRFZX" (newly added) referenced
in the page HTML.

Official Google Tag Manager install reference:
https://developers.google.com/tag-platform/tag-manager/web
